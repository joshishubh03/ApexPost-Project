# API contracts

`v1.json` and `v2.json` are the OpenAPI 3.0 documents generated by ApexPost.Api (`/openapi/v1.json`, `/openapi/v2.json`).

- They are checked by `ApexPost.Api.Tests/OpenApiDocumentTests`, which fails when the API and the committed
  contract differ.
- `ApexPost.Client` generates its NSwag client from `v2.json`.
- To refresh them after an intentional API change, run `scripts/update-contracts.ps1`. Then review the diff and add
  the change to `VERSIONING.md` (breaking or non-breaking, and why).
